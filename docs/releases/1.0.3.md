# 3D BuilderCrap 1.0.3

Projects that store slicer settings or attachments alongside supported 3MF geometry open as working copies. Save prompts for a new file. Both the desktop and MCP protect the original project from replacement, including during selection export and save-before-close.

Typed positions, dimensions and rotations now use the entered values even when handle snapping is on. Handle drags snap from the start of each stroke. Place on bed keeps the existing snap preference and exact bed contact during sideways drags.

Native 3MF files with small uniform scales can reopen at their intended physical size. When a glTF node collapses an axis, native Save writes the visible geometry in world coordinates and retains its face materials.
