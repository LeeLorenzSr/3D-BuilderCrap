# 3D BuilderCrap 1.0.2

Released source layout: maintained application code now lives in `src/BuilderCrap`. Build scripts, checks, asset tooling and documentation use the new root. Internal project and installed executable names remain unchanged.

The Windows 11 x64 installer includes the private .NET runtime, geometry worker, MCP launcher, help and notices. The optional desktop shortcut, installer AppId and model/MCP compatibility are retained. This is a source/build organization update; editing behavior and model formats are unchanged.

GitHub release preparation now builds from a matching version tag, runs focused Core checks, and creates an unpublished draft containing the installer, checksums, payload manifest, license and these notes. A maintainer reviews and publishes the draft.

Local packages remain unsigned. Existing geometry/format limits remain in the user guide. No new accessibility/DPI certification or Windows settings changes are part of this release.
