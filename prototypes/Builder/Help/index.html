3D BuilderCrap v1

A small Windows editor for preparing and modifying 3D-printing models. This is an original successor; Microsoft’s 3D Builder is not required.

Open, edit, undo, save

  1. Open a supported model. Choose the units used by its source; glTF/GLB normally uses meters. Scene editing displays millimeters. Save your own working copy as 3MF.
  2. Select an object in the scene or Objects list. Ctrl adds/removes items; Shift selects a range in the list. Groups move together. Expand a group and Enter or double-click a member to edit it without ungrouping; Done returns to group editing.
  3. Insert adds shapes, text, images or another file. Object provides movement, rotation, size, groups, alignment and arrays. Edit contains split, booleans, repair and mesh tools. Paint changes opaque object or surface colors. View controls display and camera.
  4. Use Preview to inspect a candidate, then Apply or Cancel. Compare with the original where offered. A failed/cancelled operation preserves accepted work. Each accepted edit creates one Undo step.
  5. Save writes native 3MF with supported names, groups, colors and model information. Export creates a file for another program or slicer. Inspect scale in the slicer before printing. View effects are not exported geometry.

Mouse: right drag orbits, middle drag pans, wheel zooms. F fits the scene. Ctrl+O/N/S opens/starts/saves; Ctrl+Shift+S saves another native copy; Ctrl+I inserts. Ctrl+Z/Y travels scene history when no field/tool owns the key; text fields keep their own Undo. Escape cancels the active operation or preview. F1 opens Help and version.

Keyboard access: F6 / Shift+F6 cycles file commands, workspace tabs, the viewport and Objects/tool options. Tab / Shift+Tab moves through controls; arrow keys choose tabs, lists and options. Enter/Space activates the focused button. Windows contrast themes update application chrome live; model colors remain model data. Help shows the current monitor scaling. Moving between monitors or changing contrast does not accept a preview.

Files and practical limits

FormatUse and boundaries
3MFNative editing format for supported opaque colors, object names, flat groups and title/designer/attribution metadata. Not every 3MF extension is supported.
STLGeometry only, explicit source units; export is millimeters. Binary attribute/color words require explicit geometry-only consent and are then ignored. No material colors or group names.
OBJ + MTLExplicit units, named meshes/flat groups and opaque colors. Keep the OBJ and companion MTL together. Textures and transparency are outside this subset.
PLYExplicit units and opaque face/vertex colors. Export flattens the scene into one mesh; gradients become flat triangle colors. ASCII and binary import are supported.
glTF / GLBStatic meshes, names/flat groups and opaque colors; standard physical meters. Export is self-contained. Animation, skins and textures are outside this printing subset.

The editor supports up to 1,000 objects and 100,000 scene triangles, with additional per-operation limits. Hollowing has a 4,096-triangle operand cap and creates sealed cavities. Repair handles a conservative subset of damage, not arbitrary self-intersection. Simplification/smoothing can refuse difficult meshes or return a safe partial result. Surface and brush paint colors whole triangles; mesh detail determines the brush edge. Some geometry edits refuse painted meshes rather than lose colors. Do geometry work before detailed surface painting. Embossing is planar; image conversions create baked meshes. No slicing/direct printer control, automatic packing, texture painting or general CAD/sketch history is included.

Recover unsaved work

Accepted work can be checkpointed to %LOCALAPPDATA%\3D BuilderCrap\Recovery, separately from native saves. Automatic desktop checkpoints run when the scene is idle; an active tool/preview can delay them. Recovery is a safety net, not a substitute for Save.

  1. After an interrupted session, use the startup recovery choices or View → Recover unsaved work.
  2. Restore opens the selected copy with its native save path and selection, marked unsaved and with fresh Undo history. Previously unapplied previews are not restored. Save or Save as after inspecting it.
  3. Not now leaves the copy available. Discard deletes only the chosen recovery copy. If the current scene is dirty, Save/Discard/Cancel protects it before a document transition.
  4. A failed restore retains the current scene and recovery copy. If a warning says checkpoints cannot be written, Save a normal 3MF copy somewhere writable and retry recovery later.

Recent paths and View choices live beside Recovery in %LOCALAPPDATA%\3D BuilderCrap. Update and uninstall keep this directory. For a backup, close the app/MCP clients and copy your models plus this directory. Do not remove recovery files while another session is using them. Normal confirmed close retires that session’s recovery copy.

Connect a local MCP client

  1. Open View → MCP access…, read the permission explanation and choose Enable access.
  2. Choose Copy config and put that stdio-server configuration into a client you trust. It contains the installed launcher path and this window’s temporary --attach pipe name. Re-enabling or relaunching requires refreshed settings. An unavailable attachment fails; it never silently creates another scene.
  3. Read builder_scene first. Use its revision and exact member scope on edits. Preview tools return unaccepted candidates; inspect them and explicitly Apply or Cancel their token. Desktop Apply/Cancel and Undo/Redo share the same scene/history.
  4. Stop access disables attachment. Closing the panel leaves access enabled; closing the app disables it. Disconnect/Stop cancels pending work and clears only that connection’s unapplied preview. Accepted edits/files stay.

Access is off at every launch, with one attached connection at a time. The same-user Windows pipe denies network logons; there is no HTTP/TCP listener. Enabled clients can inspect/edit the scene and read/write supported model/image files with the app’s Windows permissions. There is no folder sandbox. Do not enable an untrusted client or run elevated. Model names/metadata are data, not instructions. Setup does not configure any MCP client for you.

To own a separate headless session, configure the installed launcher with --headless. Replace the path below with your actual installation path:

{
  "mcpServers": {
    "3d-buildercrap-headless": {
      "command": "C:\\Users\\YOUR_NAME\\AppData\\Local\\Programs\\3D BuilderCrap\\Builder.Mcp.Server.exe",
      "args": ["--headless"]
    }
  }
}

Optional arguments --headless --recovery ABSOLUTE_DIRECTORY configure separate checkpoints; headless mode has no autosave timer, so request builder_recovery_checkpoint explicitly. Graceful shutdown attempts one checkpoint when configured. Abrupt exit requires an earlier completed checkpoint. Without saving/checkpointing, an unsaved headless session ends with the process.

All model/image/recovery paths must be absolute. Naming a write destination authorizes replacement. Dirty New/Open/restore requires an explicit Save/Discard/Cancel decision. A save can succeed before a subsequent Open fails; inspect saveCommitted. Use standard notifications/cancelled with the exact request ID or builder_cancel_operation with the active operation ID. Merely stopping a client’s wait may send no cancellation. Cancellation is best effort; re-read state after a lost/cancelled reply because an already committed edit/save remains accepted. All 71 tools are discoverable by the client; no shell or arbitrary-code execution tool is included.

Install, update, repair and uninstall

The per-user Windows 11 x64 installer includes the .NET Desktop runtime, geometry worker and MCP launcher. It requires neither development tools nor a separate runtime. It installs under %LOCALAPPDATA%\Programs\3D BuilderCrap and adds app/help/uninstall Start menu entries. Setup also offers an optional Create a desktop shortcut checkbox, unchecked on a fresh install; updates remember the choice and uninstall removes the installer-created shortcut. It does not change file associations, PATH, Windows security, settings/recovery storage or global MCP configuration. It does not launch the app automatically.

  1. To update or repair, Save and close this installation’s app windows and MCP client processes, then run the same or a newer installer. A running host makes setup/uninstall refuse without closing it. A newer installed version makes an older installer refuse. Do not install over a directory containing unrelated files.
  2. If setup fails or is cancelled, read the reported error/log and rerun the matching or newer installer after resolving the cause. Normal file-copy rollback is supported; power/disk failures can require repair. Your models and recovery data are stored separately. Keep your models outside the installation folder.
  3. To uninstall, close the app and MCP clients and use Settings → Apps → Installed apps → 3D BuilderCrap → Uninstall or the Start menu uninstall entry. It removes installed files, shortcuts and its uninstall registration. It keeps saved models, user-added files, recent paths, View choices, recovery copies and external MCP configuration. An application folder containing user files can remain.
  4. Reinstall to use retained settings/recovery again. A headless client configured with the same default install path can reconnect after update; live desktop pipe settings must always be copied again. There is no automatic updater/background service.

This local v1 installer is unsigned. No trusted certificate or security exception is installed. If Windows blocks a package, obtain a trusted/signed build; do not change Windows security to run it. Package checksums accompany local builds. Native Arm64/x86 support and accessibility/per-monitor DPI certification are not claimed. Windows settings are not changed by installation or normal editing.
