# Optional desktop performance probes

Retained diagnostic source outside Builder.slnx. The performance projects measure isolated WPF work against supplied frozen assemblies. ExpandedGroups.README.md describes the original scheduling assumptions.

Generate the matching performance fixture mode, provide your own compatible frozen binaries, and review each runner before use. Original measured outputs/captures are not included. Do not interpret retained historical constants or comparison hashes as a successful current run.

These probes are optional; use [normal verification](../../../docs/verification.md) for ordinary source changes. Do not change Windows settings or start an accessibility/DPI campaign as part of these tools.
