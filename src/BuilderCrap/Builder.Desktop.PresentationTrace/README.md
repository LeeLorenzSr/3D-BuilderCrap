# Optional input/capture diagnostic host

Retained diagnostic source outside Builder.slnx. This host and its native observer instrument synthetic expanded-group interactions against supplied Desktop/Core assemblies. Build.ps1 and the project accept a frozen binary directory.

The historical native capture series, reference images, binary snapshots and timing reports are not included in this public source repository. Review the source/configuration and supply your own matching input/reference data before running it. A captured compositor response is not physical input-to-photon latency.

This is a diagnostic session with its own lifecycle, not the normal editor launcher; never load unsaved user work into it. It is not part of the standard build or [fresh-checkout checks](../../../docs/verification.md).
